SILVERHAND FILMS — WEB v2

SUBIR A GITHUB
1. Entra a tu repositorio silverhandfilms.github.io > pestaña Code.
2. Add file > Upload files. Arrastra TODO el contenido de esta carpeta
   (index.html, LEEME.txt y la carpeta assets). Los archivos con el mismo nombre se reemplazan.
3. Commit changes. Espera 1-2 minutos y recarga con Ctrl + F5.

CAMBIOS RÁPIDOS (index.html)
- WhatsApp y mensaje: busca "Configuración rápida".
- Agregar un video de YouTube: busca "Para agregar un video".
- Textos de cada cliente: busca el nombre del cliente y cambia la línea <p> de al lado.
